# TaskPulse - Node.js Express ToDo Web Application

TaskPulse is a modern, responsive full-stack ToDo web application built with **Node.js** and **Express.js**.

---

## ⚡ Features

- **Interactive Dashboard**: Modern dark glassmorphic design system.
- **Quick Task Addition**: Rapid task entry bar with category and due date selection.
- **One-Click Checkbox Completion**: Instant completion toggle with strike-through styling.
- **Filter Tabs & Search**: Filter tasks by tab (All, Active, Completed), Category, and Priority.
- **JSON Backup Export**: Export task data as a JSON file directly from the dashboard.
- **RESTful API**: Clean REST API endpoints at `/api/todos` and server health check `/health`.
- **Automated Tests**: Tested using Jest & Supertest.

---

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Automated Tests
```bash
npm test
```

### 3. Start Development Server
```bash
npm run dev
```

### 4. Start Production Server
```bash
npm start
```

Visit the application in your browser at: **`http://localhost:3000`**
